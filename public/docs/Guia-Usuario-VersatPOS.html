🚀 Inicio y Acceso al Sistema

1.
🌐 Acceder al Sistema
Abrir navegador web / Ingresar URL del sistema / Esperar carga completa
2.
🔐 Iniciar Sesión
Email: tu correo electrónico / Contraseña: tu contraseña personal / Click en "Iniciar Sesión"
3.
🏢 Seleccionar Unidad
Si eres ADMIN: Verás opción de cambiar entre SPA y Barbería
Si tienes rol asignado: La unidad se selecciona automáticamente
✅ Primer Ingreso: Si es tu primera vez, deberás cambiar la contraseña temporal por una personal.

👥 Roles y Permisos del Sistema

👑 ADMINISTRADOR

Acceso completo a todo el sistema

🏠 Dashboard

Vista consolidada de todas las unidades, métricas globales, reportes avanzados

👥 Usuarios

Crear, editar, eliminar usuarios de cualquier rol, resetear contraseñas

📊 Reportes

Acceso a todos los reportes, exportación en Excel/PDF, análisis avanzado

⚙️ Configuración

Precios variables, comisiones, parámetros del sistema

📋 RECEPCIONISTA

Gestión diaria del negocio

📅 Citas

Crear, editar, cancelar citas de todos los clientes y empleados

💰 Ventas POS

Procesar ventas, aplicar descuentos, manejar métodos de pago

👥 Clientes

Registro, edición, gestión de créditos, bloqueo de clientes

💳 Caja

Abrir/cerrar caja, registrar gastos e ingresos adicionales

💇‍♂️ ESPECIALISTAS (SPA/Barbero)

Gestión de sus propias actividades

📅 Mis Citas

Ver solo sus citas asignadas, actualizar estados (En curso, Completada)

💸 Mis Comisiones

Ver sus comisiones generadas, estados y montos

⚠️ Restricciones: No pueden crear citas, ver otros clientes, ni acceder a inventario o reportes.

📅 Gestión de Citas

Acceso: Menú → Agenda

📋 Crear Nueva Cita

1.
👤 Seleccionar Cliente
Campo obligatorio - Buscar por nombre o teléfono / Crear nuevo cliente si no existe
2.
📅 Fecha y Hora
Campo obligatorio - Calendario interactivo / Horarios disponibles según empleado / Duración automática según servicio
3.
💇‍♂️ Seleccionar Servicio
Campo obligatorio - Catálogo de servicios / Precio visible / Duración estimada
4.
👨‍💼 Asignar Empleado
Campo obligatorio - Lista de empleados disponibles / Filtrado por unidad (SPA/Barbería)
5.
📝 Notas (Opcional)
Información adicional / Preferencias del cliente / Observaciones especiales

🔄 Estados de Citas

📅 SCHEDULED

Cita programada, pendiente de confirmación

✅ CONFIRMED

Cita confirmada con cliente

⏳ IN_PROGRESS

Servicio en curso (actualizado por empleado)

✅ COMPLETED

Servicio finalizado, lista para facturar

❌ CANCELLED

Cita cancelada por cliente o negocio

🚫 NO_SHOW

Cliente no asistió a la cita

🔄 Convertir Cita a Venta

1.
🔍 Buscar Cita Completada
En la lista de citas / Filtrar por estado "Completada"
2.
💳 Click en "Ir a Venta"
Botón visible solo en citas completadas sin venta asociada
3.
🛒 POS Precargado
Sistema abre POS con cliente y servicios ya cargados
⚠️ Importante: Si el servicio tiene precio variable, aparecerá un modal para seleccionar el precio final antes de continuar con la venta.

📅 Rango de Fechas

Filtrar citas por período específico

👤 Estado

Filtrar por estado de la cita

💇‍♂️ Servicio

Filtrar por tipo de servicio

👨‍💼 Empleado

Filtrar por empleado asignado (solo ADMIN/RECEPTIONIST)

💰 Punto de Venta (POS)

Acceso: Menú → POS (ADMIN, RECEPTIONIST)

🛒 Proceso Completo de Venta

1.
👤 Seleccionar Cliente
Buscar por nombre/teléfono / Crear cliente rápido / Opcional para venta general
2.
🛍️ Agregar Items al Carrito
  • Servicios: Seleccionar de catálogo / Asignar empleado obligatorio
  • Productos: Buscar por nombre / Ajustar cantidad
  • Paquetes: Seleccionar paquete predefinido
3.
🎯 Precios Variables
Si servicio tiene precio variable: Modal para seleccionar precio dentro de rango permitido
4.
💸 Descuentos
Monto de descuento / Razón obligatoria / Requiere autorización si es alto
5.
💳 Métodos de Pago
  • 💵 Efectivo: Ingresar monto recibido, sistema calcula cambio
  • 💳 Tarjeta: Confirmar procesamiento en terminal
  • 📱 Transferencia: Confirmar transferencia bancaria
  • 📲 Billetera Digital: Yape, Plin, etc.
  • 🔄 Mixto: Combinar múltiples métodos
6.
🧾 Comprobante
Generación automática / Opción de imprimir / Enviar por email/WhatsApp

💰 Pago Mixto Detallado

1.
🔄 Seleccionar "Mixto"
Modal permite distribuir monto entre hasta 4 métodos diferentes
2.
📊 Distribuir Montos
Ingresar monto para cada método / Sistema valida que la suma sea igual al total
3.
✅ Confirmar
Sistema procesa cada método por separado / Genera comprobante detallado
⚠️ Requisitos: La caja debe estar abierta para procesar ventas. Cada servicio debe tener un empleado asignado.
✅ Comisiones Automáticas: El sistema calcula y registra comisiones automáticamente al completar la venta.

👥 Gestión de Clientes

Acceso: Menú → Clientes (ADMIN, RECEPTIONIST)

👤 Crear Nuevo Cliente

1.
📝 Información Básica
  • Nombre: Obligatorio - Nombre completo del cliente
  • Teléfono: Obligatorio - Debe ser único en el sistema
  • Email: Opcional - Para envío de comprobantes
  • Género: Opcional - Masculino/Femenino/Otro
2.
📋 Información Adicional
  • Notas: Preferencias, alergias, información relevante
  • Empleado Preferido: Especialista de preferencia
3.
✅ Validaciones
Teléfono no debe existir / Email debe tener formato válido / Nombre mínimo 1 carácter

💳 Gestión de Créditos

1.
➕ Agregar Crédito
Botón "Agregar Crédito" / Monto numérico / Razón del abono
2.
💰 Usar Crédito
En POS: Se muestra saldo disponible / Opción de usar crédito como método de pago
3.
📊 Historial
Registro completo de abonos y usos de crédito

🔒 Bloqueo de Clientes

1.
🚫 Bloquear Cliente
Botón con ícono de candado / Razón obligatoria / Confirmación requerida
2.
⚠️ Restricciones
Cliente bloqueado no puede: Crear citas, Realizar ventas, Usar créditos
3.
🔓 Desbloquear
Botón "Desbloquear" / Se requiere justificación / Se registra en historial

Clientes creados en período específico

Activos, Bloqueados o Todos

💇‍♂️ Servicios y Paquetes

Acceso: Menú → Servicios → Servicios (ADMIN, RECEPTIONIST)

🆕 Crear Nuevo Servicio

1.
📝 Información Básica
  • Nombre: Obligatorio - Nombre descriptivo del servicio
  • Precio: Obligatorio - Precio base o fijo
  • Duración: Obligatorio - Tiempo en minutos
  • Unidad: Obligatorio - SPA o BARBERIA
2.
💰 Tipos de Precio
  • FIJO: Precio único e invariable
  • VARIABLE: Precio puede cambiar, requiere aprobación
  • RANGO: Precio entre mínimo y máximo
  • COTIZACIÓN: Precio se define al momento
3.
📊 Configuración Avanzada
  • Precio Mínimo: Para servicios variables
  • Precio Máximo: Límite superior permitido
  • Requiere Aprobación: Si necesita autorización ADMIN
  • Categoría: Agrupación lógica de servicios

📦 Gestión de Paquetes

Acceso: Menú → Servicios → Paquetes
1.
📦 Crear Paquete
  • Nombre: Obligatorio - Nombre atractivo del paquete
  • Precio Fijo: Obligatorio - Precio total del paquete
  • Duración: Obligatorio - Tiempo total estimado
  • Servicios: Obligatorio - Mínimo un servicio incluido
2.
💰 Configuración de Comisiones
Cada servicio puede tener porcentaje de comisión independiente / Se calcula sobre precio del paquete
3.
🛒 Venta y Canje
Se vende como item en POS / Se canjean servicios en citas individuales / Control de consumos

🔍 Filtros y Búsqueda

🔍 Búsqueda

Por nombre de servicio

📂 Categoría

Filtrar por categoría asignada

🏢 Unidad

SPA, BARBERIA o ambas

💰 Rango de Precios

Filtrar por rangos predefinidos

📦 Gestión de Inventario

Acceso: Menú → Inventario → Productos (ADMIN, RECEPTIONIST solo lectura)

🆕 Crear Nuevo Producto

1.
📝 Información Básica
  • Nombre: Obligatorio - Nombre descriptivo
  • Tipo: Obligatorio - Uso interno, Para venta, Ambos
  • Unidad: Obligatorio - SPA o BARBERIA
2.
💰 Configuración de Precios
  • Precio Venta: Opcional - Precio para clientes
  • Precio Costo: Opcional - Precio de compra
  • Stock Actual: Cantidad disponible
  • Stock Mínimo: Alerta automática (default: 5)
3.
📊 Información Adicional
  • Código de Barras: Para escaneo rápido
  • Descripción: Detalles del producto
  • Proveedor: Información de proveedor

📊 Gestión de Stock

1.
📉 Stock Bajo
Alerta automática cuando stock < stock mínimo / Producto se muestra en rojo
2.
🔄 Ajustes de Stock
Botón "Ajustar Stock" / Motivo obligatorio / Se registra movimiento
3.
📋 Movimientos
Historial completo: Compras, Ventas, Ajustes, Uso interno

🔍 Filtros y Búsqueda

🔍 Búsqueda

Por nombre o código de barras

📂 Categoría

Filtrar por categoría de producto

🏢 Tipo

Uso interno, Para venta, Ambos

📊 Estado Stock

Crítico, Bajo, Normal, Alto

⚠️ Importante: Productos sin stock no se pueden vender en POS. RECEPTIONIST solo puede ver inventario, no puede modificar.

💳 Caja Registradora

Acceso: Menú → Caja → Apertura/Cierre (ADMIN, RECEPTIONIST)

🔓 Apertura de Caja

1.
💰 Monto Inicial
Campo obligatorio - Efectivo en caja al inicio del día
2.
🏢 Unidad Automática
Se asigna según unidad del usuario / Solo una caja por unidad
3.
✅ Confirmación
Sistema registra apertura con timestamp / No se puede abrir si ya hay una abierta

🔒 Cierre de Caja

1.
💰 Monto Declarado
Campo obligatorio - Total de efectivo contado
2.
📊 Conteo de Denominaciones
Billetes: S/200, S/100, S/50, S/20, S/10
Monedas: S/5, S/2, S/1, S/0.50, S/0.20, S/0.10
3.
📝 Notas y Firma
Notas del día (opcional) / Firma digital del responsable
4.
📊 Cálculo Automático
Sistema calcula diferencia: Declarado - Esperado
Muestra: Sobrante, Faltante o Exacto

📋 Movimientos de Caja

1.
💸 Gastos
Monto (obligatorio) / Razón (obligatoria) / Categoría (opcional)
2.
💰 Ingresos Adicionales
Monto (obligatorio) / Razón (obligatoria) / Tipo (opcional)
3.
📊 Historial Completo
Todas las entradas y salidas con timestamp y responsable
⚠️ Restricciones: Solo se pueden registrar movimientos si la caja está abierta. No se pueden abrir múltiples cajas por unidad.

💸 Gestión de Comisiones

Acceso: Menú → Comisiones (Todos los roles, con filtros)

📊 Estados de Comisiones

⏳ PENDING

Generada automáticamente, pendiente de aprobación

✅ APPROVED

Aprobada por administrador, lista para pago

💰 PAID

Comisión pagada al empleado

❌ VOID

Comisión anulada (devolución, cancelación)

🧮 Cálculo Automático

1.
📊 Fórmula Base
Comisión = Precio del servicio × Porcentaje del empleado
2.
💰 Base de Cálculo
Se calcula sobre precio bruto (antes de descuentos)
Configuración: basedOnGross: true (por defecto)
3.
📝 Registro Automático
Se genera al completar venta / Se asocia a venta y empleado

💇‍♂️ EMPLEADOS

💡 Tips y Mejores Prácticas

🚀 Tips de Productividad

  • Atajos de Teclado: Usa Ctrl+K para búsqueda rápida
  • Refresh Automático: Los datos se actualizan cada 30 segundos
  • Filtros Guardados: El sistema recuerda tus últimos filtros
  • Navegación Rápida: Usa el menú lateral para cambiar entre módulos

💰 Tips de Ventas

  • Confirmación de Citas: Llama o envía mensaje 1 día antes
  • Venta Cruzada: Ofrece productos relacionados durante el servicio
  • Paquetes: Vende paquetes para asegurar ingresos futuros
  • Créditos: Fomenta el uso de créditos para fidelizar clientes

📋 Tips de Operación

  • Apertura de Caja: Hazlo siempre a la misma hora
  • Inventario: Revisa stock crítico al final del día
  • Comisiones: Revisa pendientes semanalmente
  • Backups: El sistema hace respaldos automáticos diarios

🔒 Tips de Seguridad

  • Contraseñas: Cambia tu contraseña cada 3 meses
  • Cierre de Sesión: Cierra sesión al terminar tu turno
  • Datos Sensibles: No compartas tus credenciales
  • Reportes: Revisa reportes de actividad sospechosa

✅ Buenas Prácticas Recomendadas

  • Atención al Cliente: Siempre confirma los datos del cliente
  • Calidad de Datos: Mantén actualizada la información de contacto
  • Comunicación: Coordina con otros empleados sobre disponibilidad
  • Mejora Continua: Reporta cualquier error o sugerencia

⚠️ Errores Comunes a Evitar

  • No cerrar caja: Siempre cierra caja al final del día
  • Citas sin confirmar: Confirma todas las citas del día siguiente
  • Inventario descuidado: Actualiza stock inmediatamente después de compras
  • Ignorar alertas: Presta atención a las notificaciones del sistema
