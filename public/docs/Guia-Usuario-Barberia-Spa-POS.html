👑 Administrador

🏠 Dashboard Principal

Acceso: Inicio → Dashboard

📊 Métricas Principales

  • 💰 Ingresos del día: Total de ventas realizadas
  • 👥 Clientes atendidos: Número de clientes únicos
  • 📅 Citas del día: Citas programadas vs completadas
  • 📦 Productos vendidos: Unidades vendidas del inventario

💰 Gestión de Caja (Cash Register)

Acceso: Inicio → Caja Registradora

🔄 Flujo de Ventas

1.
📋 Seleccionar Cliente
Buscar por nombre o DNI / Crear cliente nuevo si no existe
2.
🛒 Agregar Servicios/Productos
Seleccionar de catálogo / Ajustar cantidades / Verificar precios
3.
💳 Procesar Pago
  • Efectivo: Recibir dinero y calcular cambio
  • Tarjeta: Procesar tarjeta
  • Transferencia: Confirmar transferencia
  • Billetera Digital: Yape/Plin
  • Mixto: Combinación de métodos
4.
🧾 Comprobante
Boleta o Factura / Envío por email o WhatsApp / Impresión opcional

📅 Gestión de Citas

Acceso: Citas → Gestión de Citas

📋 Creación de Citas

1.
👤 Selección de Cliente
Buscar cliente existente / Crear nuevo cliente
2.
📅 Fecha y Hora
Calendario interactivo / Horarios disponibles / Duración estimada
3.
💇‍♂️ Selección de Servicio
Tipo de servicio / Especialista asignado / Unidad (Barbería/SPA)
4.
💰 Confirmación
Costo del servicio / Método de pago preferido / Recordatorio programado

📋 Recepcionista

🏠 Vista Principal del Recepcionista

Acceso: Inicio → Dashboard Recepcionista

📊 Panel de Control

  • 📅 Citas del día: Lista de citas programadas
  • 👥 Clientes esperando: En sala de espera
  • ⏰ Próximas citas: Próximos 30 minutos
  • 💰 Ingresos del día: Ventas realizadas

📅 Gestión de Citas

Acceso: Citas → Mis Citas

📋 Crear Nueva Cita

1.
👤 Datos del Cliente
Buscar cliente existente / Registrar nuevo cliente / Verificar historial
2.
📅 Programación
Seleccionar fecha y hora / Verificar disponibilidad / Asignar duración
3.
💇‍♂️ Selección de Servicio
Elegir tipo de servicio / Seleccionar especialista / Confirmar precio
4.
✅ Confirmación
Enviar recordatorio / Programar alerta / Guardar cita

💰 Ventas y Pagos

Acceso: Caja Registradora

🛒 Proceso de Venta

1.
📋 Identificar Cliente
Buscar en sistema / Crear si es nuevo
2.
🛍️ Agregar Productos/Servicios
Escanear código de barras / Buscar manualmente / Aplicar descuentos
3.
💳 Procesar Pago
  • Efectivo: Calcular cambio exacto
  • Tarjeta: Procesar en terminal
  • Digital: Escanear QR
  • Mixto: Dividir pago
4.
🧾 Entregar Comprobante
Imprimir boleta / Enviar por WhatsApp / Email opcional

💇‍♂️ Barbero/Estilista

🏠 Panel Principal del Barbero

Acceso: Inicio → Dashboard Barbero

📊 Mi Panel

  • 📅 Citas de hoy: Lista de clientes asignados
  • ⏰ Próxima cita: Siguiente cliente
  • 💰 Servicios realizados: Conteo del día
  • ⭐ Calificaciones: Feedback de clientes

📋 Mis Citas

Acceso: Citas → Mis Citas

📅 Vista del Día

  • 🕐 Horario: Lista cronológica
  • 👤 Cliente: Nombre y historial
  • 💇‍♂️ Servicio: Tipo y duración
  • 📝 Notas: Preferencias especiales

🔄 Durante la Cita

1.
👋 Recepción del Cliente
Confirmar servicio solicitado / Verificar historial previo / Revisar preferencias
2.
💇‍♂️ Ejecución del Servicio
Registrar inicio del servicio / Anotar observaciones / Tomar fotos de antes/después
3.
✅ Finalización
Marcar servicio completado / Calificar satisfacción / Programar siguiente cita
